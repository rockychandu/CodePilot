# CodePilot Design System Guide

## Overview
The CodePilot Design System enforces commercial visual quality, accessibility, dark mode aesthetics, and cohesive developer tool design.

## Design Tokens (`tokens.css`)

### Color Palette (Dark Navy Theme)
- **Background Darkest**: `#030712`
- **Surface**: `#111827`
- **Surface Hover**: `#1F2937`
- **Accent Cyan**: `#38BDF8` (Glow: `rgba(56, 189, 248, 0.35)`)
- **Accent Purple**: `#8B5CF6`
- **Accent Emerald**: `#10B981`

### Typography Scale
- **Sans-serif**: `'Inter', system-ui, sans-serif`
- **Monospace**: `'JetBrains Mono', 'Fira Code', monospace`

### Component Utilities
- Buttons: `.btn`, `.btn-primary`, `.btn-secondary`, `.btn-outline`
- Badges: `.badge-tag`, `.badge-easy`, `.badge-medium`, `.badge-hard`
- Cards: `.card`, `.card-glass`
- Modals: `.modal-overlay`, `.modal-container`
- Console Badges: `.output-status-pill`, `.status-accepted`, `.status-error`
