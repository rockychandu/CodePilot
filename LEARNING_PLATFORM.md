# CodePilot — Developer Learning Platform

## 1. Course Curriculum Hierarchy
```
Course (e.g., "Modern Python Systems & Architecture")
 └── Module (e.g., "Module 1: AST Inspection & Sandboxes")
      ├── Video Lesson (with interactive chapter markers)
      ├── PDF / Architecture Whitepaper Lesson
      ├── Interactive Quiz
      └── Practical Coding Problem
```

---

## 2. Interactive Features
- **Video Player**: Timestamped chapter markers allowing seamless seeking between technical topics.
- **PDF Viewer**: Embedded technical documentation reader.
- **Automated XP & Progress Sync**: Completing lessons persists progress to `learning_progress` and increments user XP.
